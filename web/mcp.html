TypesetLLM · MCP

Connect Codex to TypesetLLM with one command:

codex mcp add typesetllm --url https://typesetllm.onrender.com/mcp

Run codex mcp list to verify it was added. Reconnect or start a new Codex session if the tools do not appear.

Use TypesetLLM to convert report.md into a PDF and save it here.

Rendering happens on TypesetLLM’s server. Your client downloads the resulting PDF into its workspace from a temporary link.

Claude Code

claude mcp add --transport http typesetllm https://typesetllm.onrender.com/mcp

Use claude mcp list to check the connection.

Tools

convert_markdown_to_pdf
Returns a short lived HTTPS download URL, filename, expiration time, and rendering warnings.
typesetllm_status
Checks renderer readiness.

Optional local adapter

The stdio adapter calls the hosted conversion API and writes PDFs locally. It requires Python and a repository checkout.

cd mcp
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
codex mcp add typesetllm-local -- python /absolute/path/to/mcp/server.py
