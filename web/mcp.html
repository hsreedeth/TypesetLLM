TypesetLLM · MCP

Call TypesetLLM as a tool from Claude Code, Codex CLI, or any other MCP client, instead of pasting Markdown into the browser. One tool renders a PDF and saves it locally; a second checks whether the renderer is warmed up.

View on GitHub

Install

cd mcp
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

Add to Claude Code and Codex CLI

Claude Code

claude mcp add typesetllm -- python /absolute/path/to/mcp/server.py

Codex CLI

codex mcp add typesetllm -- python /absolute/path/to/mcp/server.py

Add to Claude Desktop

Add this to claude_desktop_config.json and restart Claude Desktop.

{
  "mcpServers": {
    "typesetllm": {
      "command": "python",
      "args": ["/absolute/path/to/mcp/server.py"]
    }
  }
}

Tools

convert_markdown_to_pdf
Renders Markdown to a typeset PDF via /convert and saves it locally. Returns the file path and any renderer quality warnings.
typesetllm_status
Pings /ready — useful since the hosted instance can cold-start after idling.

Configuration

Points at the public deployment by default. Override with environment variables to target a different instance or change where PDFs land:

VariableDefault
TYPESETLLM_URLhttps://typesetllm.onrender.com
TYPESETLLM_OUTDIR~/typesetllm-output
TYPESETLLM_TIMEOUT90 seconds
