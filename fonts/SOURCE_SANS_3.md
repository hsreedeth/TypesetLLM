# Source Sans 3 provenance

Static TTF faces (Regular, Semibold, Bold, Italic, Bold Italic) and `OFL_SourceSans3.txt` come from Adobe's [source-sans release branch](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e), pinned to commit `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`. The licence is SIL Open Font License 1.1. The font files are bundled and loaded by path; rendering does not download them or depend on system fonts. If these files are missing, the RolePilot style falls back to the repository's bundled `Inter-Variable.ttf` sans serif.
